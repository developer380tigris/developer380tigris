### Обо мне

Разработчик с фокусом на **Counter-Strike 1.6, игровые клиенты и серверную инфраструктуру**.

Работаю на разных уровнях: от игровой логики и модификаций клиента до backend-сервисов и веб-интерфейсов. Уделяю внимание производительности, надёжности и удобству сопровождения.

- **C++** — модификации игровых клиентов и интеграции.
- **Pawn / AMX Mod X / ReAPI** — серверные плагины и игровые механики.
- **PHP / Laravel** — API, веб-приложения и панели управления.
- **TypeScript / React / Next.js** — пользовательские интерфейсы.
- **Go / PostgreSQL / Redis** — backend-сервисы, хранение данных и кеширование.
- **Linux** — настройка и сопровождение серверов.
